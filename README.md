# ytdl-extension

Manifest V3 browser extension (Brave and other Chromium browsers) that downloads progressive YouTube streams.
Personal-use only: use it on content you have the right to save. Downloading may violate YouTube's Terms of Service.

## Develop
    npm install
    npm run build     # outputs dist/
    npm test
    npm run lint

Load `dist/` via `brave://extensions` → Developer mode → Load unpacked.
